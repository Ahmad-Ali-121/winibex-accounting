# API

Node, Express, MySQL. REST over JSON. Base path `/api/v1`.

Status: Conventions fixed. Endpoint list is the plan, filled in per phase.

## Conventions

### Money in JSON
Always an object, never a bare number:

```json
{ "minor": 12000000, "currency": "PKR" }
```

`minor` is an integer. Floats in a money field are rejected by validation.

### Dates
`YYYY-MM-DD` for accounting dates. ISO 8601 UTC for timestamps.

### Idempotency
Every request that creates or posts money carries an `Idempotency-Key` header,
a UUID generated by the client when the form opens. The server stores the key
with the result for 24 hours and returns the same result for a repeat. This is
what stops a double tap or a flaky mobile connection from posting the same
expense twice.

### Errors
```json
{
  "error": {
    "code": "UNBALANCED_JOURNAL",
    "message": "Debits and credits do not match.",
    "field": null,
    "details": { "debit": 500000, "credit": 450000 }
  }
}
```

`code` is stable and machine-readable. `message` is safe to show a user.

Validation warnings are not errors. A create request with warnings returns
`409` with the warnings listed. The client shows them, and resubmits with
`"acknowledged_warnings": ["POSSIBLE_DUPLICATE"]` to proceed.

### Pagination
`?page=1&per_page=50`. Response includes `total`, `page`, `per_page`, and the
totals row for the whole filtered set, not just the page.

### Search
`?q=` searches across description, reference, client name and amount on the
server. Never client-side.

### Auth
- Short-lived access token, sent as `Authorization: Bearer`
- Refresh token: httpOnly secure cookie on web, secure storage on Android
- Passwords hashed with argon2id
- Rate limit on login
- Every response is scoped by role and the `payroll_visible_to_all` setting

### Transactions in MySQL
Every write runs inside a MySQL transaction. The posting engine writes the
transaction, its tax and charge lines, its journal lines and the audit entry
in one unit. Any failure rolls everything back.

### Rate limiting
Login: 5 attempts per 15 minutes per account and per IP. Money-creating
endpoints: 60 per minute per user.

### Phase 9
The MCP server imports `modules/*/service.js` directly. No HTTP hop, no
duplicated logic.
