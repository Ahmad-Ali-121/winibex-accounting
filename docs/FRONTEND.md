Features never import from another feature's folder. Shared needs go in
`core/` or through a provider exposed by the owning feature.

## Riverpod

Riverpod 3 with code generation only. No manually declared providers, no
`StateNotifier`, no `ChangeNotifier`, no `StateProvider`.

### Read-only async data: a functional provider

```dart
@riverpod
Future<List<Account>> accounts(Ref ref) async {
  final api = ref.watch(accountsApiProvider);
  return api.list();
}
```

### Parameterised: arguments on the function become the family

```dart
@riverpod
Future<LedgerPage> ledgerPage(
  Ref ref, {
  required int accountId,
  required int page,
  String? search,
}) async {
  final api = ref.watch(transactionsApiProvider);
  return api.ledger(accountId: accountId, page: page, search: search);
}
```

### State with actions: an AsyncNotifier class

```dart
@riverpod
class TransactionDraft extends _$TransactionDraft {
  @override
  Future<DraftState> build(int? transactionId) async {
    if (transactionId == null) return DraftState.empty();
    final api = ref.watch(transactionsApiProvider);
    return DraftState.fromTransaction(await api.get(transactionId));
  }

  void setCurrency(String code) {
    final current = state.value;
    if (current == null) return;
    state = AsyncData(current.copyWith(currency: code));
  }

  Future<void> submit() async {
    final current = state.value;
    if (current == null) return;

    state = const AsyncLoading();
    state = await AsyncValue.guard(() async {
      final api = ref.read(transactionsApiProvider);
      final saved = await api.submit(current.toRequest());
      return DraftState.fromTransaction(saved);
    });

    if (!ref.mounted) return;
    ref.invalidate(ledgerPageProvider);
    ref.invalidate(accountsProvider);
  }
}
```

### Rules

- Every provider is async when its source is the network. The UI handles all
  three states with `switch` on `AsyncValue`, never `.value!`
- `ref.watch` in `build`, `ref.read` inside actions
- After any `await` in a notifier action, check `ref.mounted` before touching
  `state` or other providers
- After a write, invalidate the providers whose data changed. Never patch a
  balance locally. Balances come from the API, always
- Riverpod 3 retries failed providers automatically. Set an explicit retry
  policy rather than relying on the default, and never let a write be retried
  automatically. Writes carry an idempotency key, see `docs/API.md`
- Keep experimental Riverpod features (offline persistence, mutations) out of
  financial flows until they are stable
- Run `dart run build_runner watch -d` during development. Generated
  `*.g.dart` and `*.freezed.dart` files are committed

### Rendering

```dart
class AccountsList extends ConsumerWidget {
  const AccountsList({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final accounts = ref.watch(accountsProvider);
    return switch (accounts) {
      AsyncData(:final value) when value.isEmpty =>
          const EmptyState.accounts(),
      AsyncData(:final value) => AccountsTable(accounts: value),
      AsyncError(:final error) => ErrorPanel.from(error),
      _ => const AccountsSkeleton(),
    };
  }
}
```

## Money

- A `Money` value type holding `int minorUnits` and `String currency`
- Never `double` for money, anywhere, including JSON parsing
- Formatting lives in one place: thousands separators, currency code, negatives
- The app never adds money to produce a total that is shown as a balance.
  Totals come from the API

## Theming

All design values live in one file: `lib/core/theme/app_theme.dart`.

- `_Palette` holds raw hex values. A rebrand changes only this section
- `AppColors` is a `ThemeExtension` of semantic colours: `accent`, `moneyIn`,
  `negative`, `pending`, `reversed`, `rule` and so on. Read with
  `context.colors`
- `AppSpacing`, `AppRadii`, `AppSizes` for every dimension
- `AppText.amount(context)` for every number, always tabular figures
- `AppTheme.light` and `AppTheme.dark` are the only `ThemeData` in the app
- A `Color(0x...)`, raw font size, `EdgeInsets` literal or radius literal in a
  feature folder fails review

Direction: ledger paper. Red ink for negatives, ruled tables rather than
floating cards, radius that follows hierarchy (controls tight, containers
softer, tables none). Palette: Graphite and petrol. Near-monochrome greys with a single petrol
accent. Money in uses the accent, negatives use red ink.

Typeface: Onest, one family throughout. Chosen for clean, minimal shapes and
open forms that stay legible at small sizes in dense tables. Verified to carry
the OpenType `tnum` feature. Its default digits are proportional, so every
number must render through `AppText.amount` or `AppFonts.tabular`, or columns
will not line up.

### Fonts

Bundled as assets, never fetched at runtime with `google_fonts`. A runtime
fetch adds a network round trip on first load and can be blocked by the COEP
header the Wasm build needs.

```yaml
flutter:
  generate: true
  fonts:
    - family: Onest
      fonts:
        - asset: assets/fonts/Onest-Regular.ttf
        - asset: assets/fonts/Onest-Medium.ttf
          weight: 500
        - asset: assets/fonts/Onest-SemiBold.ttf
          weight: 600

Use the static weight files, not the variable font, so `FontWeight` maps
directly. Onest is OFL licensed.
```

## Strings

Every user-facing string lives in `lib/l10n/app_en.arb`. Flutter's `gen-l10n`
generates `AppLocalizations`, which code reads as
`AppLocalizations.of(context).actionSave`.

- No string literal shown to a user anywhere in feature code
- Parameters use ARB placeholders, never string concatenation
- Tooltip text for accounting terms lives in the same file with a `term`
  prefix, and `lib/core/glossary/glossary.dart` maps each `Term` to its label
  and tooltip
- New screen, new keys. Group by prefix: `nav`, `action`, `field`, `status`,
  `step`, `hint`, `confirm`, `err`, `warn`, `flag`, `empty`, `term`
- API error codes map one-to-one to `err` keys

English only today. Urdu later means adding `app_ur.arb`, with no code change.

Setup in `pubspec.yaml`:

```yaml
dependencies:
  flutter_localizations:
    sdk: flutter
  intl: any
```

`l10n.yaml` in the app root sets the output to `lib/l10n/generated/`.

## Tooltips

- `TermTooltip(term: Term.debit, child: ...)` is the only way a tooltip is shown
- Text comes from `app_en.arb` through `core/glossary/glossary.dart`
- Works on hover for desktop and long-press for touch

## Web build

```bash
flutter build web --wasm --release
```

Route-level deferred imports for heavy modules such as reports and payroll.
The server must send COOP and COEP headers for Wasm multithreading, see
`docs/DEPLOY.md`.

## Open decision: table package

Needs a short spike before Phase 1, comparing:

- A free grid package for sorting, paging and column resizing
- Syncfusion DataGrid under its community licence, which is richer but adds a
  licence to track

Criteria: server-side paging, frozen columns, keyboard navigation, dark theme
quality, copy row support, and performance at 5,000 rows on web.
